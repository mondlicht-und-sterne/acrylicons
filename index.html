Installation

1. Download and Extract
theAcrylicons-v5.0.zip

2. Run theinstall.shscript, it is easier.

or 2. Moving Folder
Move the folder Acrylicons to:
~/.local/share/icons/

3. Activate the theme

KDE Plasma: Settings → Appearance → Symbols
GNOME: Gnome Tweaks → Appearance → Symbols
Linux Mint / LMDE: Settings→ Appearance → Themes → Symbols

4. Select the ‘Acrylicons’ icon theme from the settings.
